# PAN SAUCE
A full-stack web application for University.

## To run project:
On windows:

1. Open **Command Prompt** or **PowerShell**.
2. Navigate to the project root directory:
   ```cmd
   cd path\to\your\project
   ```
3. And run run.bat file
    ```cmd
        run.bat
    ```
Or simple navigate to it via your file explorer and double-click.
